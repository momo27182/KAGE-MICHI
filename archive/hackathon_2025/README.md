# 2025年ハッカソン成果物

このフォルダには、ハッカソン時点で作成されたコード、スライド、動画、キャッシュ、生成HTMLを当時の状態のまま保存しています。

## 基準として確認する実装

- `github_main_snapshot/app.py`: GitHubの`main`から取得した最新のStreamlit版
- `app_realtime.py`: 整理前のローカルで最も後期だったStreamlit版
- `requirements.txt`: 当時記録された依存パッケージ一覧（バージョンは未固定）
- `shadow_navi.pptx`: 18枚の発表資料

他の `app*.py` は試作・デザイン・機能追加の過程を残す派生版です。調査や比較には使えますが、新規開発の変更先にはしません。

## 取り扱い

- 原則として直接編集・上書き・削除しない。
- 再実行によりキャッシュやHTMLが変化する可能性があるため、必要ならコピーして検証する。
- 新しい製品コードはプロジェクトルートの `src/` に作る。
- 過去版から移植した処理は、移植元ファイルと理由を `log.md` に記録する。
- `cache/`、`動画/`、`shadow_map.html`はローカルには保存するが、容量や生成物の性質から通常のGit管理対象外とする。
