# 地名検索と候補選択

最終更新: 2026-08-11

## 目的

地名、住所、施設名から出発地・目的地候補を探し、緯度経度を直接入力しなくても地点を選べるようにする。検索、候補選択、地点反映、経路計算を別操作にし、検索や候補変更だけで重い影・経路計算を起動しない。

## 操作の流れ

1. 出発地または目的地の検索語を入力する。
2. 「候補を検索」を押す。この操作時だけ外部サービスへ問い合わせる。
3. 名称、住所、加工済みデータ中心からの距離、範囲内外を確認して候補を選ぶ。
4. 「選択した候補を地点へ反映」を押す。範囲外候補は反映できない。
5. 緯度経度を確認し、「経路を計算」を押す。

入力中の自動補完は行わない。同じ検索条件はStreamlitで7日間キャッシュし、画面再実行や同一検索による不要な問い合わせを防ぐ。

## 候補の整理

- 和歌山県・日本を検索語へ加え、`country_codes=jp`と対象範囲付近の`viewbox`で候補を偏らせる。
- 公開Nominatimで日本語駅名が駅本体より周辺施設へ偏る既知ケースに対し、対象地域の主要駅3件（和歌山駅・田中口駅・紀和駅）はOSMの英語名へ検索語を対応づけ、画面上は入力した日本語名で表示する。この対応表は対象範囲拡大時にローカル地名索引へ置き換える。
- 検索サービスの結果をそのまま経路計算へ渡さず、UI中立のモデルへ変換する。
- 名称とほぼ同一の座標で重複を除き、範囲内、中心からの距離、名称、提供元IDの順で安定して並べる。
- 結果なし、全候補が範囲外、範囲内に複数候補、タイムアウト、サービス停止を別の状態として表示する。
- 範囲判定には加工済みデータの`manifest.json`にある中心と半径を使う。

## Nominatim利用条件

現在の既定プロバイダーはOpenStreetMap Foundationの公開Nominatimである。公式の[Nominatim Usage Policy](https://operations.osmfoundation.org/policies/nominatim/)に従い、次を実装条件とする。

- 利用者が検索ボタンを押したときだけ問い合わせ、自動補完や一括検索をしない。
- アプリを識別する固有User-Agentを送る。
- `RateLimiter`で1リクエスト/秒未満に制限し、単一スレッドで利用する。
- 結果をキャッシュし、同じ検索を繰り返し送らない。
- OpenStreetMapの出典を画面に表示する。
- 可用性保証はないため、失敗時も緯度経度入力を利用できる。

Geopy 2.5の[Nominatim API](https://geopy.readthedocs.io/en/stable/index.html)で、タイムアウト、件数、国コード、viewbox、住所・名称詳細を明示している。

## 設定と切替

公開サービスへの依存をコード更新なしで切り替えられるよう、次の環境変数を利用できる。

- `KAGE_MICHI_GEOCODER_DOMAIN`: Nominatim互換サービスのドメイン
- `KAGE_MICHI_GEOCODER_USER_AGENT`: 運用主体を識別できるUser-Agent

利用者が入力した検索語は外部サービスへ送信されるため、個人情報や機密情報を入力しないよう画面で案内する。本格公開・利用者増加の前に、独自Nominatimまたは利用規模に合う事業者と、サーバー側共有キャッシュへの切替を判断する。

## 固定テストケース

| 種別 | 入力 | 固定する確認 |
|---|---|---|
| 施設名 | 和歌山駅 | 範囲内候補として名称・住所・距離を表示 |
| 住所 | 和歌山市美園町5丁目 | 範囲内候補として選択可能 |
| 地名 | 和歌山市 | 範囲内候補として名称・住所・距離を表示 |
| 候補なし | 存在しない場所 | 候補なしとして再入力を案内 |
| 範囲外 | 大阪駅 | 候補は表示するが地点へ反映できない |
| 障害 | タイムアウト・停止 | 緯度経度入力が使えることを案内 |

固定ケースは外部サービスの現在の応答内容に依存させず、検索結果をテスト用に固定して、分類・並び順・表示状態を再現する。

## 改善前後の実サービス確認

2026-08-11に、固有User-Agentと1秒間隔を設定し、公開Nominatimへ利用者操作相当の単発検索を行った。

| 入力 | 改善前の問題 | 改善後 |
|---|---|---|
| 和歌山駅 | 日本語検索では駅前交番、店舗、マンション等が並び、駅本体が上位10件に出なかった | 駅名対応表により駅本体1件、中心から34m、範囲内 |
| 田中口駅 | 固定確認なし | 駅本体1件、中心から624m、範囲内 |
| 紀和駅 | 固定確認なし | 駅本体1件、中心から1,466m、範囲内 |
| 和歌山市美園町5丁目 | 候補の範囲や曖昧さを区別しなかった | 範囲内候補を取得し、複数なら名称・住所・距離付きで選択 |
| 和歌山市 | 最初の候補をそのまま採用し得た | 市役所付近の候補1件、中心から約1,243m、範囲内として表示 |

外部検索結果はOSMの編集やNominatimの更新で変わり得るため、この表は観測記録であり永続的な保証ではない。分類ロジックの再現性は前節の固定テストで保証する。

## 現時点の限界

- 公開Nominatimの検索品質と稼働状況に依存する。
- 7日キャッシュは単一Streamlitプロセス内であり、複数サーバー間では共有しない。
- 候補の距離は加工済みデータ中心からの直線距離で、出発地からの徒歩距離ではない。
- 検索範囲は和歌山駅周辺約1.7kmの加工済みデータに固定されている。
- 検索結果の名称・住所はOpenStreetMapの登録状況に依存する。
