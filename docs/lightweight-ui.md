# 軽量Streamlit画面

最終更新: 2026-08-11

## 目的

加工済みOSMデータと分割済みの影・経路計算を利用し、検索操作のたびにOSM取得や不要な再計算を行わない最小画面を提供する。

## 再計算境界

| 変更した入力 | データ読込 | 影計算 | 経路探索 |
|---|---:|---:|---:|
| 変更なし | 再利用 | 再利用 | 再利用 |
| 出発地・目的地・日向ペナルティ | 再利用 | 再利用 | 再計算 |
| 基準・比較日時 | 再利用 | 各日付の該当5分値を選択 | 変更した時刻だけ再計算 |
| データディレクトリ・manifest更新 | 再読込 | 再検証・再読込 | 再計算 |

道路データと日付別の日陰率は`st.cache_resource`、経路比較は`st.cache_data`で保存する。画面操作時にはPLATEAU建物からの影生成や全道路の日陰判定を実行しない。要求時刻は成果物のタイムゾーンへ変換し、未来値を使わないよう直前の5分値へ切り下げる。成果物の破損、OSM道路版の不一致、時刻欠損、安定エッジキーの過不足は明示エラーとし、旧計算へ暗黙に戻さない。同日の2時刻は1日分の成果物を共有する。

## 表示内容

- 基準・比較日時それぞれの最短／日陰優先経路線、出発地、目的地
- 経路距離、推定日陰率、推定日向距離、表示処理時間
- 対象日時、計算実行時刻、データ取得処理日時、対象範囲
- OpenStreetMapの出典
- 推定値であること、PLATEAU LOD1、凸包影、5m道路サンプリングという限界
- 要求日時と実際に使用した5分刻み時刻、昼間／夜間（直達日射なし）の区別

## 地名検索

地名、住所、施設名を明示的に検索し、候補を地点へ反映できる。検索・候補選択・地点反映だけでは影や経路を計算せず、最後に「2時刻を比較」を押したときだけ既存処理を実行する。候補の安定化、対象範囲判定、外部サービスの利用条件は[地名検索と候補選択](place-search.md)を参照する。

## 実データ測定

2026-09-25、和歌山駅周辺の加工済みOSM道路と2026-08-11の事前計算済みPLATEAU日陰率で`measure_ui_cache.py`を実行した。Streamlitのbare modeによる同一プロセス内キャッシュを使用している。

| 操作 | 合計時間 | 結果 |
|---|---:|---|
| 初回 | 0.788秒 | 日陰成果物読込0.072秒、経路0.173秒を含む |
| 同一入力を再表示 | 0.0004秒 | 道路・日陰成果物・経路を再利用 |
| 時刻を14:04から14:09へ変更 | 0.089秒 | 使用値は14:00から14:05へ変更 |
| 目的地を変更 | 0.205秒 | 道路・日陰成果物を再利用し、経路だけ再計算 |

時刻変更2秒以内、地点変更1秒以内というIssue #33の目標を満たした。数値は単一開発環境の代表値であり、低性能端末や同時利用時の保証値ではない。

## 起動と測定

```powershell
.\.venv\Scripts\python.exe -m streamlit run src\streamlit_app.py
.\.venv\Scripts\python.exe scripts\measure_ui_cache.py
```

`data/prepared/wakayama-station`はGit管理対象外であり、存在しない環境では先に`prepare_osm_data.py`を実行する。
