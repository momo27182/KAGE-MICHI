# 2時刻の経路・日陰率比較

最終更新: 2026-09-25

## 目的

基準日時と利用者が指定した比較日時について、最短経路と日陰優先経路を同じ条件で計算し、移動距離・徒歩時間・推定日陰率・推定日向距離の変化を確認できるようにする。

この表示はPLATEAU LOD1建物と5m道路サンプリングによる推定であり、気温、WBGT、熱中症リスク、医学的安全性を直接示すものではない。

## 仕様

- 比較日時の初期値は基準日時の1時間後。日付を独立入力でき、翌日・前日の比較にも対応する。
- 同一日時は比較にならないため明示エラーにする。
- 各要求日時は、その日付の事前計算成果物に対して直前の5分値へ解決する。未来値は使わない。
- 日付別成果物の欠損、破損、OSM道路版不一致、時刻欠損は明示エラーにし、別日や旧計算へ暗黙に戻さない。
- 同日の2時刻では同じ日陰成果物を1回だけ読み込み、同一入力の経路結果もキャッシュから再利用する。

結果表には4経路を並べ、各時刻の日陰優先による距離増加と、日陰優先経路どうしの推定日陰率の変化を表示する。詳細欄には要求時刻、実際に使った5分値、昼間／夜間、データ版、計算条件を示す。

## 実データ性能

2026-09-25、和歌山駅周辺の加工済みOSM道路と2026-08-11の事前計算済みPLATEAU日陰率を使用した。同一プロセス内のStreamlitキャッシュを含む代表値であり、端末や同時利用条件に対する保証値ではない。

| 操作 | 合計時間 | キャッシュ挙動 |
|---|---:|---|
| 14:00と15:00を初回比較 | 0.911秒 | 道路・1日分の日陰成果物を共有し、2時刻の経路を計算 |
| 同じ2時刻を再表示 | 0.0007秒 | 日陰成果物と両時刻の経路を再利用 |
| 比較時刻だけ16:00へ変更 | 0.199秒 | 基準時刻の経路を再利用し、比較時刻だけ再計算 |
| 地点を変更 | 0.184秒 | 道路・日陰成果物を再利用し、両時刻の経路を再計算 |
