# 公開ライブカメラによる影検証の予備試験

試行日: 2026-11-06

## 結論

和歌山県の「亀の川 羽鳥橋水位観測所」と「大門川 伊勢橋」を試した。固定画角と更新時刻を持つ公的カメラは、影の変化を継続観察する仕組みの予備試験には使える。一方、羽鳥橋は現行範囲外、伊勢橋は範囲内だが川面と護岸が中心で対象道路が映らない。このため、どちらもIssue #41の道路日陰率を数値検証する地点には採用しない。

画像は調査時だけ一時取得し、リポジトリには保存しない。公開閲覧できることを、画像の自動収集・保存・再配布が許可されていることとはみなさない。

## 試したカメラ

- 名称: 亀の川 羽鳥橋水位観測所
- 管理・配信: 和歌山県の河川監視カメラ
- 所在地: 和歌山市内原
- 橋の公式座標: 北緯34.17179、東経135.19912
- 現在画像: `https://kasensabo01.pref.wakayama.lg.jp/hyoujidata/camera/C04200.jpg`
- 現行モデル中心（和歌山駅付近）からの直線距離: 約6.785km
- 現行対象半径: 約1.7km

座標は和歌山県の橋梁維持修繕計画に記載された羽鳥橋の起点側位置を使った。カメラ自身の厳密な設置座標・方位ではない。

## 2026-11-06の確認結果

| 条件 | 結果 | 判定 |
| --- | --- | --- |
| 公的な配信元 | 和歌山県の河川監視カメラとして確認 | 合格 |
| 固定画角 | 河川、護岸、橋、画面左端の道路を固定画角で確認 | 予備試験には合格 |
| 画像解像度 | 352×240px | 道路日陰率には不足 |
| 更新時刻 | 11:15 JST確認時の`Last-Modified`は11:03 JST | 時刻照合は可能だが約12分差 |
| 道路区間 | 画面左端に短い道路・歩道区間のみ | 数値集計には不足 |
| 影の視認性 | 河川・護岸・橋上で日向と影の境界を確認 | 定性観察には使用可能 |
| 現行モデルとの重なり | 和歌山駅中心から約6.8km、半径1.7km外 | 不合格 |
| 過去映像 | 現在画像URLだけでは履歴を取得できない | 未達 |
| 利用・保存条件 | 自動収集・解析・保存・再配布の明示許諾を未確認 | 未達 |

確認した1フレームでは、画面中央の河川・護岸には明瞭な影がある。ただし、KAGE-MICHIが評価する歩行道路の大部分は写らず、道路全体の0〜100%日陰率を人手で付与できない。

## 採用判断

今回のカメラは次の用途に限定する。

- 固定カメラ画像を時刻付きで確認する手順の試験
- 日向・日陰境界が公開画像で判別できるかの定性確認
- 今後の候補カメラを評価するチェック項目の作成

次の用途には使わない。

- 現行の和歌山駅周辺PLATEAU成果物との誤差集計
- 道路日陰率の正解値としてのCSV登録
- 許諾を確認しない定期ダウンロード、長期保存、再配布

## 次の候補に必要な条件

次に探す1地点は、以下をすべて満たすことを採用条件とする。

1. 和歌山駅から半径約1.7km以内、またはその地点のPLATEAU・道路日陰率を別途生成できる。
2. 同じ道路区間全体が固定画角に入り、影境界を判別できる。
3. 分単位の撮影時刻または信頼できる更新時刻が分かる。
4. 晴天時の午前・正午・午後を取得でき、欠測や遅延を記録できる。
5. 自動取得、解析、保存、研究・開発利用の条件を運営者へ確認できる。

YouTubeの長時間ライブは、12時間を超える配信がアーカイブされない場合があり、DVRの巻き戻し範囲にも制限がある。そのため、YouTube上で24時間配信されていることだけを過去時刻の取得保証とはしない。公式の静止画履歴、運営者提供データ、または利用許諾を優先する。

## 現行範囲内の追加調査

調査日: 2026-11-06

和歌山県の公開`CameraList.csv`と水位局座標`waka_suii_st.csv`、近畿地方整備局の河川・道路ライブカメラ配置図を確認した。和歌山駅中心から半径約1.7km以内に入る県管理カメラとして、大門川の伊勢橋を確認した。

### 大門川 伊勢橋

- 公式座標: 北緯34.242500、東経135.182222
- 和歌山駅中心からの直線距離: 約1.413km
- 現在画像: `https://kasensabo01.pref.wakayama.lg.jp/hyoujidata/camera/C10301.jpg`
- 画像解像度: 352×240px
- 2026-11-06 11:26 JST確認時の`Last-Modified`: 11:10 JST
- 現行OSM歩行グラフの最近傍エッジ: カメラ座標から約6.1m

画像は川面、護岸、両岸の細い管理通路が中心で、KAGE-MICHIが評価する一般道路・歩道区間全体は映っていない。近傍にOSM道路エッジはあるが、その道路を画像内で一意に識別して0〜100%の日陰率を付与できないため、定量集計には不採用とする。

### 周辺候補の確認

- 大門川 鳴神橋は公式座標から和歌山駅中心まで約1.9kmで、現行半径約1.7kmの外。
- 国土交通省の紀の川河川カメラ群は紀の川沿い、和歌山河川国道事務所の道路カメラは国道24号・42号の郊外部が中心で、公式配置図上に和歌山駅周辺の道路を映す地点は確認できなかった。
- 「和歌山駅」「和歌山駅前」の公式・公開ライブカメラも検索したが、道路区間と分単位時刻を確認できる配信は確認できなかった。

### 判断

現行対象範囲内の公的固定カメラ調査は一旦終了する。伊勢橋は固定カメラ取得の技術試験用として候補に残すが、道路日陰率の精度評価には使わない。Issue #41は既存の現地撮影計画へ戻り、晴天時の12観測を優先する。将来、運営者から過去画像や別画角の提供を受けられる場合、または対象範囲を鳴神橋等へ拡大する場合に再評価する。
