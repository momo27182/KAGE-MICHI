# 現地写真を補完する影の参照データ調査

調査日: 2026-10-04

## 結論

道路単位の日陰率について、撮影場所と分単位の撮影時刻が分かる現地写真を、そのまま置き換えられる公開データは確認できなかった。雨天中は、国土地理院の空中写真による定性確認と、PLATEAU・航空レーザ点群による形状・高さの独立確認を進める。ただし、これらを現地実測と同じ「正解値」として平均誤差の計算には混ぜない。

## 候補の比較

| 候補 | 分かること | 道路日陰率の数値検証 | 採用判断 |
| --- | --- | --- | --- |
| 現地写真・観察 | 同じ場所・時刻の実際の影 | 使用可能 | 最終検証の基準として維持 |
| 国土地理院の空中写真 | 建物影の方向・大まかな長さ、過去の地物 | 原則不可 | 定性確認と地点選定に使用 |
| 国土地理院の点群 | 建物・樹木・橋を含む高さ | 影そのものではない | 提供範囲と費用を確認後、入力形状の独立検証候補 |
| PLATEAU | 建物外形・高さ・一部の屋根形状 | 影そのものではない | 現行モデル入力。実測の代替にはしない |
| Sentinel-2 | 広域の地表・植生・雲 | 不可 | 10m画素のため歩道・道路影には粗すぎる |
| Google Street View | 過去の道路景観・影の有無 | 原則不可 | 年月しか分からない場合があり、保存・キャッシュ制約もあるため補助閲覧のみ |
| 影シミュレーター同士の比較 | 実装差・計算ミス | 不可 | 回帰テストには使うが、現実との精度検証とは呼ばない |

## 判断の根拠

### 国土地理院の空中写真

地図・空中写真閲覧サービスでは400dpi画像をダウンロードでき、諸元情報から撮影年月日と地上画素寸法を確認できる。一方、公開ヘルプで明示される時刻情報は撮影年月日までで、道路日陰を太陽位置と照合するために必要な分単位の撮影時刻は確認できない。また、通常の空中写真は中心投影で地図へ直接重ねられず、重ね合わせにはオルソ画像が必要である。

したがって、影の向きが明らかに反対、存在する大きな建物がモデルにない、といった定性確認には使えるが、道路日陰率の誤差を数値化する正解データにはしない。オンライン閲覧所の最高画質画面は撮影・キャプチャを避け、利用する場合はダウンロード可能画像と測量成果の利用条件を確認する。

### 国土地理院の点群・標高

国土地理院は建物、樹木、橋、送電線を含む航空レーザ点群を提供している。点には緯度・経度・高さ、色情報、簡易分類が含まれるため、PLATEAUにない樹木や建物高さの独立確認に利用できる可能性がある。

ただし、2026年9月30日現在の公式刊行範囲図では和歌山市・紀伊半島に点群の刊行範囲を確認できない。そのため現時点で導入Issueは作らず、公開範囲が更新されたときに再評価する。

通常の数値標高モデル（DEM）は建物や樹木を取り除いた地表面の高さであり、建物影の直接検証には使えない。地形による影を追加するときの入力候補として扱う。

### PLATEAU

PLATEAUは現行の建物形状・高さ入力として有用だが、3D都市モデル自体は影の観測データではない。和歌山市の公開資料では市内全域がLOD1、LOD2はランドマーク14箇所、テクスチャ未整備とされる。LOD1は建物高さの中央値で立ち上げる原則があり、屋根形状や庇を十分に表さない。このため、同じPLATEAUから生成した別シミュレーションを正解値にすると循環検証になる。

### 衛星画像

無償で継続取得しやすいSentinel-2は可視・近赤外の最高空間分解能が10m、標準再訪が5日である。雲の影響も受ける。歩道幅や建物際の影を0〜100%で評価する用途には粗すぎるため、今回の道路日陰率検証には採用しない。

### Google Street View

公式メタデータの撮影日は年のみ、または年月までの場合があり、日・時刻が欠ける。太陽位置を再現できないため、写っている影を数値的な正解値にはできない。さらにStreet View Static APIは画像の事前取得・保存・キャッシュを原則禁止している。現地の構造や撮影候補地点を事前確認する補助閲覧に限定し、検証画像としてリポジトリへ保存しない。

## 雨天中に進める作業

1. 和歌山駅周辺で2022年撮影・縮尺1:10,000の空中写真4件を確認済み。代表候補地点の建物欠落や道路位置ずれの定性確認に使う。
2. 晴天時の撮影候補4地点は[`和歌山駅周辺の現地検証候補地点`](field-validation-sites.md)に選定済み。街路樹地点の最終確定は現地下見時に行う。
3. 現行PLATEAUとOSMの高さ差が大きい地点を、現地検証の優先候補として抽出する。
4. 国土地理院点群は和歌山市が現行刊行範囲外と確認済み。今回は導入Issueを作らず、範囲更新時に再評価する。
5. 雨が止んだら、同一地点を午前・正午前後・午後に撮影し、既存CSVへ記録する。

## 定量集計へ入れてよい参照の条件

以下をすべて満たす写真・観察だけを、`field-observations.csv`の実測値として扱う。

- 撮影地点と対象道路区間を特定できる
- タイムゾーンを含む分単位の撮影日時が分かる
- 影の境界と道路区間全体を判別できる解像度がある
- 雲の変動、撮影方向、主な影要因を記録できる
- 利用・保存・公開条件を確認できる

条件を満たさない画像は、誤差要因の候補発見や地点選定には使えるが、平均絶対誤差等の数値集計には含めない。
