# 現地撮影チェックシート

対象: 和歌山駅周辺 WV-01〜WV-04  
用途: 晴天日の現地下見・撮影・CSV記録

## 当日の中止条件

- [ ] 車道、線路、私有地へ入らずに撮影できる
- [ ] 雨、厚い雲、急な日射変化がない
- [ ] 暑さや体調に無理がない
- [ ] 人物、車両番号、住宅内部を避けられる

1つでも満たせない場合は、その地点・時間帯を中止する。現地検証のために危険な場所へ移動しない。

## 撮影地点

座標リンクは候補の中心であり、撮影位置の指定ではない。初回の下見で、公共の歩道・広場から道路区間全体が写る位置を決める。

| ID | 分類・候補座標 | 対象道路区間 | 撮影方向 |
| --- | --- | --- | --- |
| WV-01 | 駅前の開放空間 / [34.232500, 135.191700](https://www.openstreetmap.org/?mlat=34.232500&mlon=135.191700#map=18/34.232500/135.191700) | 駅前の同一歩道区間。駅舎・高架と開口部が同時に分かる範囲 | 下見時に真北0°基準で0〜359°を記録 |
| WV-02 | 中高層建物沿い / [34.232441, 135.189533](https://www.openstreetmap.org/?mlat=34.232441&mlon=135.189533#map=18/34.232441/135.189533) | 最大55.5m候補建物に接し、道路の日向・日陰境界が入る同一区間 | 建物と道路の長軸が分かる方向を下見時に固定 |
| WV-03 | 密集低層・OSM差分 / [34.232734, 135.200370](https://www.openstreetmap.org/?mlat=34.232734&mlon=135.200370#map=18/34.232734/135.200370) | PLATEAU上の低層建物と道路が同時に分かる同一区間 | 建物現況と道路影境界が入る方向を下見時に固定 |

## 下見時に1回だけ記録

各地点で以下をメモし、2回目以降も同じ位置・同じ向きを使う。

- [ ] 実際の撮影位置の緯度・経度
- [ ] カメラ方向（真北=0°、東=90°、南=180°、西=270°）
- [ ] 画面に入れる道路区間の両端（交差点、標識、建物端など）
- [ ] 立ち位置の目印
- [ ] 街路樹、庇、地形など建物以外の主要な影要因
- [ ] 撮影可否と危険要因

## 各時間帯の撮影

同じ晴天日に、できるだけ以下の3枠で撮影する。時刻を枠に合わせるために安全を犠牲にしない。

| 枠 | 目安 | WV-01 | WV-02 | WV-03 | WV-04 |
| --- | --- | --- | --- | --- | --- |
| AM | 09:00〜10:00 | [ ] | [ ] | [ ] | [ ] |
| NOON | 11:30〜12:30 | [ ] | [ ] | [ ] | [ ] |
| PM | 14:00〜15:00 | [ ] | [ ] | [ ] | [ ] |

各1回の撮影で確認する。

- [ ] スマートフォンの日時・タイムゾーンがJST（`+09:00`）
- [ ] 前回と同じ立ち位置・カメラ方向
- [ ] 対象道路区間の全体と影境界が写っている
- [ ] 空の状態が分かる写真を1枚追加
- [ ] 天候、雲の変化、主な影要因をメモ
- [ ] 人物・車両番号・住宅内部が識別できないことを確認

## 写真と観測IDの命名

観測ID:

```text
WV-<地点番号>-<YYYYMMDD>-<HHMM>
```

写真ファイル名:

```text
<観測ID>_N<方向角3桁>_<連番2桁>.jpg
```

例:

```text
WV-02-20261012-0937
WV-02-20261012-0937_N090_01.jpg
WV-02-20261012-0937_N090_02.jpg
```

- `N090`は真北から90°（東向き）。
- `_01`は道路と影、`_02`は空・天候の写真を推奨。
- CSVの`photo_reference`にはフォルダ名または主写真の相対パスを記録する。
- 原本写真はGitにコミットしない。

## CSVに入れる値

| CSV列 | 記入内容 |
| --- | --- |
| `observation_id` | 上記の観測ID |
| `location_name` | `WV-01`〜`WV-04`と分類名 |
| `latitude`, `longitude` | 実際に立った安全な撮影位置 |
| `observed_at` | 写真の分単位時刻、例: `2026-10-12T09:37:00+09:00` |
| `predicted_shade_pct` | 同じ区間・時刻のアプリ推定日陰率0〜100 |
| `observed_shade_pct` | 写真で判断した道路区間日陰率0〜100 |
| `weather` | `sunny`, `mostly_sunny`, `cloudy`, `variable` |
| `shade_source` | `building`, `tree`, `eave`, `terrain`, `other`, `none` |
| `photo_reference` | 主写真または観測フォルダの相対パス |
| `camera_direction_deg` | 真北基準の0〜359° |
| `notes` | 雲の変化、対象区間の両端、樹木・庇、安全上の変更 |

CSVは撮影後に生成し、記入例の行を実測値で置き換える。

```powershell
.\.venv\Scripts\python.exe scripts\field_validation.py template data\validation\field-observations.csv
```

記入後は集計前に必ず検証する。`summary`が生成された場合のみ、数値比較へ進む。

```powershell
.\.venv\Scripts\python.exe scripts\field_validation.py summarize `
  data\validation\field-observations.csv `
  benchmark-results\field-validation.json
```

## 後で確認する最低限

- [ ] 4地点×3時間帯の12観測がある、または欠測理由を記録した
- [ ] 全観測にJSTの分単位時刻がある
- [ ] 全観測に撮影方向と写真参照がある
- [ ] `variable`または急な雲変化の観測を単純な平均誤差と分けて解釈した
- [ ] 結果は観測地点・日時の範囲に限定し、医学的な安全を保証する表現をしていない
