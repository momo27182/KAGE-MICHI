# 最短ルートと日陰優先ルートの比較

## 目的

距離最短と日陰優先のトレードオフを、同一の道路・影・日時条件で比較する。どちらも推定であり、安全や実際の徒歩時間を保証しない。

## 計算方法

- 道路エッジの日陰判定は一度だけ行い、同じ複製グラフを2つの探索に使う。
- 最短ルートはOSMの`length`を重みとして選ぶ。
- 日陰優先ルートは、日向エッジの距離へ画面指定のペナルティを掛けた`shade_cost`を重みとして選ぶ。
- 両ルートとも、距離、日向距離、`100 × (1 - 日向距離 / 距離)`による推定日陰率を集計する。
- 推定徒歩時間は比較用に80m/分で切り上げる。
- 両探索は同じキャッシュ済み影を使い、比較のためにOSM取得や影生成を重複させない。

## 表示

- 地図: 日陰優先は緑の実線、最短は赤の破線。
- 比較表: 距離、推定徒歩時間、推定日向距離、推定日陰率。
- 差分: 日陰優先ルートの距離増加と日陰率の差を符号付きで表示。
- 同一ルートの場合は差を0として扱う。

## 代表ケース

2026-09-23 14:00 JST、和歌山駅周辺の既定地点、日向ペナルティ10で実画面確認。

| 指標 | 最短 | 日陰優先 |
|---|---:|---:|
| 距離 | 1,129m | 1,237m |
| 推定徒歩時間 | 15分 | 16分 |
| 推定日向距離 | 1,129m | 815m |
| 推定日陰率 | 0.0% | 34.1% |

距離増加は画面丸めで+107m、日陰率差は+34.1ポイント。初回計算処理7.120秒、同一条件のキャッシュ後0.006秒。初回値はデータ読込等を含む端末・セッション依存の参考値である。

## 制約

- 日陰判定は道路区間の中央点による二値判定で、部分日陰を表さない。
- 建物高さ欠損は10m、影形状は凸包による簡易モデルで、PLATEAUは未導入。
- 距離・徒歩時間・日陰率は推定であり、暑熱環境や安全を保証しない。
