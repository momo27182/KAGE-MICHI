# ADR 0003: 道路日陰率の事前計算に5mサンプリングを使う

- 状態: 採用
- 決定日: 2026-09-24

## 背景

中央点1点の二値判定は部分日陰を表現できない。交差長方式は高精度だが、複雑な結合影と全道路の交差計算が重い。多数時刻を事前計算できる精度と速度の均衡が必要である。

## 決定

- 道路線分を等長区間に分け、各区間の中央点を5m以下の間隔で評価する。
- 日陰率を0〜1で保存し、日向距離と経路コストへ連続的に反映する。
- 交差長方式は代表ケースの比較基準とし、通常の事前計算・経路検索には使わない。
- 検索時に全道路を再判定せず、事前計算した値を読む。

## 理由

和歌山駅周辺10,262エッジの固定比較で、5m方式は1.364秒、交差長基準への平均絶対誤差0.009395だった。10m方式は0.783秒・0.016072、中央点方式は0.126秒・0.070651、交差長方式は67.468秒だった。5m方式は中央点方式から誤差を約86.7%削減し、オフライン事前計算として許容できる時間だった。

## 影響

- 部分日陰を経路結果の日向距離へ反映できる。
- 1時刻・全道路のfloat32値は約0.039 MiB、5分刻み24時間は約11.274 MiBとなる。
- 中央点方式より計算量と保存容量が増えるため、時刻・地域・影モデル版をキーにした事前計算が必要。
- 1日時点のみの判断であり、低太陽高度・別季節・現地検証の結果によって間隔を再評価する。
