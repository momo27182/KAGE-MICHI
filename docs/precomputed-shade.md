# 5分刻み道路日陰率の事前生成

Issue #31では、画面操作のたびに全建物の影と全道路の日陰率を再計算せず、加工済みOSM道路とPLATEAU LOD1建物から日単位の成果物をオフライン生成する。

## 生成

```powershell
.\.venv\Scripts\python.exe scripts\prepare_shade_ratios.py
```

既定条件は和歌山駅周辺、2026-08-11、Asia/Tokyo、00:00〜23:55の5分刻み、道路上5mサンプリングである。`--date`、`--start-time`、`--end-time`、`--interval-minutes`、`--spacing-m`、`--output`で変更できる。同名出力は上書きしない。

## 保存仕様

`data/prepared/shade/<地域>/<日付>/`へ次を保存する。このディレクトリはGit管理対象外である。

- `shade-ratios.npz`: 時刻、昼夜、太陽高度、安定エッジキー `(u, v, key)`、`float32`日陰率
- `manifest.json`: 地域、時間帯、タイムゾーン、間隔、CRS、入力・出力SHA-256、モデル版、意味チェックサム、件数、計測値

一時ディレクトリですべて生成・検証してからディレクトリ単位で確定する。失敗時に部分成果物を公開せず、既存成果物も変更しない。読込時はファイルSHA-256、配列構造、値域、キー重複、時刻順、意味チェックサム、必要に応じて入力版を検証する。

## 夜間の意味

太陽高度が0度以下の行は `daylight=false`、`shade_ratio=1.0` とする。これは建物による日陰率100%ではなく「直達日射がない」ことを示す。画面では必ず夜間として表示し、建物の日陰と表現しない。

## 実測

環境: Windows、和歌山駅周辺10,262エッジ、PLATEAU 23,032建物、2026-08-11。

- 14:00〜14:10（3時刻）: 生成55.386秒、73,893 bytes、検証読込0.0165秒
- 24時間・5分刻み（288時刻、昼間162時刻）: 生成2,702.281秒（45分02秒）、ピーク468,815,872 bytes（447.1 MiB）、出力1,113,068 bytes（1.06 MiB）
- SHA-256・配列・意味チェックサムを含む完全読込5回: 平均0.0772秒、最大0.0787秒

完全読込は2秒以内の性能目標を満たした。未圧縮の値配列11.274 MiBに対し、NPZ全体は約1.06 MiBとなった。小さな再現結果は`docs/precomputed-shade-benchmark.json`に保存する。

画面への読込・経路探索統合はこのIssueの対象外である。
