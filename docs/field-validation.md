# 影推定の現地検証

## 目的

KAGE-MICHIが推定する道路日陰率と、同じ場所・時刻に観察した日陰率を比較する。現段階では精度を保証するのではなく、誤差が大きくなる条件を特定し、次の改善順を判断することを目的とする。

## 最初の検証計画

- 対象地域: 和歌山駅周辺
- 地点: 駅前の開けた道路、中高層建物沿い、低層住宅地、街路樹がある道路を各1地点以上
- 時刻: 同じ晴天日の午前、正午前後、午後から各1回以上
- 1地点につき、道路上の同一区間を同じ向きから撮影する
- アプリの指定時刻は写真の撮影時刻（日本標準時、`+09:00`）へ合わせる
- 比較対象の道路区間と撮影位置が分かるよう、地図のスクリーンショットも保存する

## 記録方法

テンプレートを生成する。

```powershell
python scripts/field_validation.py template data/validation/field-observations.csv
```

記入例の行を実測値へ置き換える。`predicted_shade_pct`と`observed_shade_pct`は0〜100の道路区間日陰率、`camera_direction_deg`は真北を0度とする撮影方向である。

`weather`は`sunny`、`mostly_sunny`、`cloudy`、`variable`から、主な実影要因`shade_source`は`building`、`tree`、`eave`、`terrain`、`other`、`none`から選ぶ。雲で日射が変わった場合は`notes`にも記録し、単純比較から除外するか分析時に区別する。

写真はGitへ直接コミットせず、個人が識別できる人物、車両番号、住宅内部が写らないようにする。必要なら加工済みの小さな画像だけを、出典・撮影時刻・削除方針とともに別途管理する。

## 集計

```powershell
python scripts/field_validation.py summarize `
  data/validation/field-observations.csv `
  benchmark-results/field-validation.json
```

出力には件数、地点数、符号付き平均誤差、平均絶対誤差、最大絶対誤差、誤差10ポイント以内の件数、実影要因別の平均絶対誤差が含まれる。`予測 - 実測`が正なら日陰を過大推定し、負なら過小推定している。

## 判定と次の改善候補

- 建物影で一貫してずれる: 建物高さ、外形、太陽位置、撮影位置を確認する
- 樹木・庇で実測だけが暗い: 樹木・庇を入力データへ加える必要性を評価する
- 時刻でずれ方が変わる: タイムゾーン、撮影時刻、太陽方位を確認する
- 雲の変化が大きい: 幾何学的な影精度とは分離し、気象状態を表示する
- 道路の一部だけで差が大きい: サンプリング間隔と道路幅の表現を再検討する

結果は限定された地点・日時の検証であり、熱中症の安全性や未観測地域の精度を保証しない。
