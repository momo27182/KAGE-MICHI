# PLATEAU LOD1とOSM建物の比較

測定日: 2026-09-24

## 結論

PLATEAU LOD1は現行OSMより建物の収録数と高さ根拠が大幅に優れるため、影計算の入力として採用する価値がある。一方、同一時刻の影計算はOSM 1.68秒に対しPLATEAU 9.12秒だった。現行画面へただちに差し替えず、時刻キーのキャッシュまたは事前計算を設計してから統合する。

## 固定条件

- 中心: 和歌山駅周辺 `34.2325, 135.1917`
- 半径: 1,700mの円に交差する建物。外形は円でクリップ
- CRS: `EPSG:6676`
- 代表日時: `2026-08-11T14:00:00+09:00`
- 影: 現行の建物外形・高さ・Pysolarを使う凸包押し出しモデル
- 入力: チェックサム検証済みの加工済みOSM / PLATEAU。比較時の外部通信なし

## 結果

| 指標 | OSM | PLATEAU | 解釈 |
| --- | ---: | ---: | --- |
| 建物フィーチャ | 6,052 | 23,032 | PLATEAUは+16,980件、3.81倍 |
| 高さ中央値 | 10.000m | 6.879m | OSMは10m補完の影響が大きい |
| 高さP10 / P90 | 7.900 / 10.000m | 3.733 / 9.948m | PLATEAUはLOD1のZ差 |
| 10m値 | 上限5,387件（89.012%） | 補完なし | OSMの真の10mと補完値は現データで分離不能 |

全体比較は22.287秒。マシン、キャッシュ、ライブラリに依存する参考値である。機械可読なスナップショットは`docs/plateau-osm-comparison.json`、再生成コマンドは次のとおり。

```powershell
.\.venv\Scripts\python.exe scripts\compare_plateau_osm.py
```

## 限界

- OSM加工時に欠損高さを10mへ置換したため、原始欠損率は復元できない。10mの5,387件は補完数の上限である。
- 外形の面積重複は1棟ごとの対応付けや位置的な正解を示さない。
- 影は現行の簡易モデルで、地形、樹木、庇、建物相互の遮蔽を扱わない。
- Pysolarは将来のうるう秒テーブル未提供警告を出す。時刻の微小差は本比較の主要差に影響しないが、実測評価では再確認する。
