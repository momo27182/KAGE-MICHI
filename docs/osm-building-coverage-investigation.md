# WV-03 OSM建物カバレッジ調査

調査日: 2026-10-04

## 目的

WV-03（34.232734, 135.200370）で、加工済みPLATEAUに多数の建物がある一方、加工済みOSM建物がほぼない原因を切り分ける。

## 結果

原因は取得範囲、座標変換、GeoPackage保存ではなく、OSM原本の局所的な建物マッピング不足である。現行の日陰成果物はPLATEAU建物を入力にしているため、この差は現在の日陰優先経路の入力欠落にはつながらない。

## 確認内容

### 加工済みデータ

- OSMとPLATEAUはどちらも`EPSG:6676`で、WV-03の投影座標は同じ空間範囲に入る。
- WV-03は和歌山駅中心から約800mで、取得半径1,700mの内側にある。
- 加工済みOSM建物は全7,870件で、WV-03からの距離別件数は50m: 0、100m: 0、150m: 0、200m: 1、300m: 17、500m: 72。
- 加工済みPLATEAU建物は全23,032件で、同じ集計は50m: 59、100m: 220、150m: 392、200m: 597、300m: 1,036、500m: 1,961。
- OSMnxキャッシュ内の建物応答は2026-08-09 14:21:35 UTC時点で、`building`タグ付き要素7,953件を含む。したがって、建物取得クエリ全体が失敗したわけではない。

### 現在のOSM原本

OSMnx経由で現在のOverpass応答を再取得した。WV-03からの距離別件数は50m: 0、100m: 0、150m: 0、200m: 3、300m: 55であった。

200m以内の建物は増えているが、150m以内の未整備域は現在も残る。新しい建物way `1556379827`は、公式OSM API上で2026-09-05 15:38:21 UTCにversion 1として作成されており、8月取得版後も周辺のマッピングが進んでいる。

## 判断

- 加工ロジックの修正Issueは作らない。再取得だけでWV-03中心の欠落は解消しない。
- OSM建物をPLATEAUの代替または正解値として使わない。特に地域別カバレッジを確認せずに建物数・影面積を比較しない。
- WV-03は引き続き現地検証候補とする。PLATEAU建物の現況と、OSMの空白が実際の建物不在ではないことを写真で確認する。
- 将来、PLATEAU未整備地域へ展開するときは、OSM建物カバレッジ診断と入力品質表示を独立Issueとして設計する。
