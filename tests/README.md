# tests

自動テストと検証コードを置くフォルダです。

最初に、太陽が地平線下の場合、建物高さが欠損する場合、部分的に日陰となる道路、経路が存在しない場合をテスト対象にします。

`test_architecture.py`は製品モジュールが重い任意依存なしでimportできること、内部依存に循環がないこと、アプリケーション層へ交換可能な実装を注入できることを確認します。

`test_prepared_osm_data.py`は小さな合成データを保存・再読込し、実行時ローダーがOSM取得を呼ばないこと、追跡情報、対象範囲、誤上書き防止、欠損ファイル検出を確認します。

標準ライブラリだけの現在のテストは、次のコマンドで実行します。

```powershell
python -m unittest discover -s tests -v
```
